## 💡 How I Approach Engineering

### Understand before implementing.

코드가 어떻게 동작하는지뿐 아니라, 왜 그런 구조를 선택했는지 이해하려고 합니다.

### Design for change.

당장의 구현 속도와 함께, 요구사항이 변경되었을 때의 영향 범위와 유지보수성을 고민합니다.

### Use AI, retain responsibility.

AI를 개발 생산성을 높이는 도구로 활용하되, 결과물의 검증과 최종 판단은 개발자의 책임이라고 생각합니다.

### Communicate with clarity.

기술적인 결정을 다른 사람에게 설명할 수 있어야 좋은 협업이 가능하다고 믿습니다.
